# AI-Native Technical Writing & DevDocs Samples

Welcome to my central repository for developer documentation samples, API references, and technical writing projects. This repository serves as a living portfolio of my work as I specialize in bridging the gap between complex software systems and clear, actionable developer documentation.

---

## 🛠️ The Workspace: AI-Native Workflow

This repository is built and maintained using an **AI-native development workflow**, leveraging cutting-edge LLMs to optimize documentation accuracy, code validation, and structure.

* **IDE Integration:** Powered by **GitHub Copilot** in VS Code for real-time code snippet generation, markdown formatting assistance, and structural consistency.
* **Terminal Integration:** Powered by **Gemini** at the command line for rapid scripting, linting, automation tasks, and quick conceptual checks.

This hybrid approach ensures that the documentation is not only precise but also follows modern, agile development practices.



## 🚀 Key Focus Areas

* **API Documentation:** Transforming complex REST APIs into highly readable Postman collections and OpenAPI specifications.
* **Docs-as-Code:** Managing documentation using the same tools as code (Git, GitHub, Markdown, automated linters).
* **Developer Experience (DX):** Creating clear quick-start guides and error-handling documentation that reduce developer friction.

# How to run this repository

Run the following commands:

```sh
bundle install
npm install
npm run convert
bundle exec jekyll serve --source docs
```

Open http://127.0.0.1:4000 in a web browser.
