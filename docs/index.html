How this site is built

The site is itself a docs-as-code sample. Every change goes through the same pipeline.

  1. Write

    Markdown pages in Git, built with Jekyll and hosted on GitHub Pages.

  2. Lint

    A Vale grammar check runs on every pull request against the Google style rules.

  3. Release

    A GitHub Actions workflow writes internal release notes from merged pull requests and a weekly summary.

  4. Publish

    Each page shows a last-updated date from Git history, so readers can see how fresh it is.
